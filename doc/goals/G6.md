# Goal 6 — 同时输出中英双版日报

P2 phase. After this goal each daily run produces two files instead of
one: a fully-Chinese version (Chinese titles + Chinese summaries) and
a curated English version (LLM-selected papers, original English
titles and abstracts). Same selection, same scoring — only the
presentation differs.

This goal also adds `title_zh` to the LLM brief schema so the Chinese
report no longer has English titles mixed in.

---

## 一句话目标

`pipeline.py` 在 LLM 启用时输出两个文件：`*_zh.md`（全中文）和 `*_en.md`
（LLM 选过、英文呈现），共享同一份打分、同一份分组、同一次 LLM 调用。

## 已有基础

- `src/ecobio_daily/pipeline.py`：`run_pipeline_from_items` 已经在 `build_digest` 后调
  `_attach_llm_briefs`；写文件的 `output_path` 逻辑也在这里
- `templates/digest_zh.md.j2`：当前模板，支持 `llm_brief` 优先 + 老路径降级
- `src/ecobio_daily/llm_digest.py`：generate_section 返回的 dict 含 `items[].title` 但**没有** `title_zh`
- `config/digest.yaml`：`output_pattern: "{year}/{month}/ecobio_digest_1d_{date}_zh.md"`（硬编码 `_zh`）

## 范围

**DO:**

- `templates/prompts/digest_section_zh_system.md.j2`：JSON schema 加 `title_zh` 字段：
  - "凝练中文标题，不逐句翻译，<= 20 字"
  - 整段 `items[]` schema 调整为：`title`（原英文，原样保留）+ `title_zh`（新增中文凝练）
- `templates/digest_zh.md.j2`：每条 item 的标题用
  `scored.llm_brief_item.title_zh if scored.llm_brief_item and scored.llm_brief_item["title_zh"] else scored.item.title`
- **新建** `templates/digest_en.md.j2`：纯英文呈现，**保留 LLM 选出的同一份候选集**和分组顺序；
  body 用 `item.summary`（原 abstract）；不渲染 `summary_zh` / `why_it_matters` / `evidence_type` / `caveat`；
  保留 References + Looking Forward
- `config/digest.yaml`：`output_pattern: "{year}/{month}/ecobio_digest_1d_{date}_{lang}.md"`
- `src/ecobio_daily/pipeline.py`：
  - `_output_path` 接受 `lang` 参数并填入 pattern
  - 当 `llm_client is not None`：渲染 zh 模板 + en 模板，写两份文件
  - 当 `llm_client is None`（legacy）：只渲染 zh 模板（保持向后兼容）
  - 返回 `Path` 改为返回 zh 文件路径（保持已有调用方契约）
- `src/ecobio_daily/render.py`：扩展为接受 template_path（已经接受了，无需大改）
- `scripts/run_daily.py`：加 `--template-en` CLI 参数，默认 `templates/digest_en.md.j2`
- 测试：
  - `tests/test_render.py`：新增 `test_render_en_uses_original_english`（确认英文版用原 abstract）
  - `tests/test_render.py`：新增 `test_render_zh_uses_title_zh_when_present`
  - `tests/test_pipeline.py`：新增 `test_pipeline_writes_both_zh_and_en_when_llm_enabled`
  - `tests/test_pipeline.py`：新增 `test_pipeline_writes_only_zh_when_llm_disabled`
  - `tests/test_llm_digest.py`：mock 响应里加 `title_zh`，确保解析穿透到 dict

**DON'T:**

- 不改 LLM 评分逻辑
- 不改章节分组逻辑（`build_digest`）
- 不改缓存（prompt 变化会自然让旧缓存失效）
- 不加新依赖
- 不动 `data/processed/*-scored.json` 落盘格式
