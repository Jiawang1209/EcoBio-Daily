# Goal 9 — PubMed DOI 提取 + 同日跨源去重

A small follow-up surfaced while reviewing G8 output. Same paper
appeared twice in the 2026-05-27 Highlights — once from PubMed
(URL is the pubmed.ncbi.nlm.nih.gov UID page) and once from Europe
PMC (URL is doi.org/...). Two reasons:

1. `parse_pubmed` doesn't extract DOI → `dedup.extract_doi` returns None for PubMed items → G7 cross-day dedup can't match them with their Europe PMC twin
2. The current dedup is **cross-day only**; intra-day duplicate DOIs (same paper, different source URLs, same day) are not filtered

This goal closes both gaps.

---

## 一句话目标

让 `parse_pubmed` 把 DOI 放进 `SourceItem.id`，并在 pipeline 中加 `deduplicate_by_doi`
对当日候选集做 DOI 级去重（保留第一次出现）。

## 已有基础

- `src/ecobio_daily/fetch.py::parse_pubmed`：PubMed eutils 响应里的 `articleids` 数组每条有 `idtype` / `value`，其中一项是 `{"idtype": "doi", "value": "10.1016/..."}`
- `src/ecobio_daily/dedup.py::extract_doi(item)`：从 `item.url` / `item.id` 里抓 DOI
- `src/ecobio_daily/scoring.py::deduplicate_items(items)`：当前按 URL 去重
- `src/ecobio_daily/pipeline.py::run_pipeline_from_items`：
  - 流程：window 过滤 → `deduplicate_items`(URL) → `filter_seen`(跨日 DOI) → 评分 …
  - G9 要在 URL 去重之后、`filter_seen` 之前插入 `deduplicate_by_doi`

## 范围

**DO:**

- 改 `src/ecobio_daily/fetch.py::parse_pubmed`：
  - 从 `record["articleids"]` 找 `idtype == "doi"` 的条目
  - 抓到 → `SourceItem.id` 设为 DOI 字符串；抓不到 → 保留旧的 uid 行为
  - 不动 `url`（依然指向 pubmed.ncbi 页，方便点击）
- `src/ecobio_daily/dedup.py` 新加：
  - `deduplicate_by_doi(items: list[SourceItem]) -> list[SourceItem]`
  - 第一次见到的 DOI 保留；后续相同 DOI 丢弃；无 DOI 的全保留
- `src/ecobio_daily/pipeline.py::run_pipeline_from_items`：
  - 在 `deduplicate_items(windowed_items)` 之后、`filter_seen(...)` 之前插入 `unique_items = deduplicate_by_doi(unique_items)`
- 测试：
  - `tests/test_fetch.py` 加一条 `test_parse_pubmed_extracts_doi_from_articleids`
    - 构造一个含 `articleids` 的 payload，验证 `item.id` 是 DOI
  - `tests/test_dedup.py` 加：
    - `test_deduplicate_by_doi_keeps_first_occurrence`
    - `test_deduplicate_by_doi_preserves_items_without_doi`
  - `tests/test_pipeline.py` 加：
    - `test_pipeline_drops_intra_day_doi_duplicates`：两条同 DOI 不同 URL → 仅一条进 digest

**DON'T:**

- 不改 `extract_doi` 的实现（让 PubMed 也能被它识别就靠 id 替换）
- 不改 `filter_seen`（跨日逻辑独立）
- 不动 URL 跳转目标（pubmed.ncbi 仍然是 PubMed 条目的 URL）
- 不加新依赖
