# Goal 10 — LLM 幻觉防线（A4 / P2b）

The biggest remaining trust issue with the digest is silent
hallucination — the LLM-written Chinese summary could introduce
numbers, species names, methods, or causal claims that aren't in
the source abstract, and we'd never know.

This goal adds a per-item grounding check: after generate_section
writes a brief, a second cheap LLM call validates that each
`summary_zh` + `why_it_matters` is grounded in the original abstract.
Ungrounded items get flagged in the rendered digest so the reader
knows to defer to the English version.

---

## 一句话目标

每条 `llm_brief_item` 渲染前，用 `deepseek-v4-flash` 做一次 grounding 校验，
不通过的条目在 markdown 里加 ⚠️ 提示并让模板降级回原 abstract。

## 范围

**DO:**

- `config/llm.yaml`：
  - 在 `routing` 下加 `grounding_check: cstcloud_flash`
- 新建 `templates/prompts/grounding_check.md.j2`：
  - 给 LLM 看英文 abstract + 中文 summary_zh + 中文 why_it_matters
  - 让它判断："中文是否引入了 abstract 没有的具体数字/物种/方法/地点？是否把相关性写成因果？"
  - 输出严格 JSON：`{"grounded": <true|false>, "score": <0-10>, "reason": "<<=30 字中文>"}`
- 新建 `src/ecobio_daily/llm_grounding.py`：
  - `check_groundedness(abstract: str, brief_item: dict, client: LLMClient) -> dict | None`
  - 调用 `client.chat(task="grounding_check", response_format="json_object")`
  - 解析失败 / LLM 调用失败 → 返回 `None`（不阻断管线）
  - 成功返回 `{"grounded": bool, "score": int, "reason": str}`
- `src/ecobio_daily/models.py`：`ScoredItem` 加 `llm_grounding: dict | None = None`
- `src/ecobio_daily/pipeline.py`：
  - 在 `_attach_llm_briefs` 内部，**给每条带 `llm_brief_item` 的 item 跑一次 check_groundedness**
  - 结果挂到 `scored.llm_grounding`
  - 通过的（`grounded == true` 且 `score >= 7`）保持不变
  - 不通过的：**不删 `llm_brief_item`**，让模板看到 `llm_grounding` 不通过时显示警告并降级摘要为英文
  - stderr 加一行 `LLM grounding: K passed, M failed`
- `templates/digest_zh.md.j2`：
  - 当 `scored.llm_grounding` 不通过：
    - 不渲染 summary_zh / why_it_matters / evidence_type / caveat
    - 渲染一行 `> ⚠️ 中文摘要未通过事实核查（理由：{{ reason }}）。请以下方英文版为准。`
    - 然后渲染原 `scored.item.summary`（英文 abstract）
- 新建 `tests/test_llm_grounding.py`：
  - mock LLM 返回 `{"grounded": true, "score": 9, "reason": "ok"}` → 返回 dict
  - mock LLM 返回 `{"grounded": false, "score": 3, "reason": "数字未对应"}` → 返回 dict
  - mock 不可解析 JSON → 返回 None
  - mock HTTP 500 → 返回 None
  - 验证 prompt 里同时包含 abstract 和 summary_zh
- `tests/test_pipeline.py`：
  - 注入 mock grounding 函数，验证 `scored.llm_grounding` 被赋值
- `tests/test_render.py`：
  - 一条带 `llm_grounding={"grounded": false, ...}` 的 item → 输出包含 "⚠️ 中文摘要未通过事实核查" 和原 abstract，不含 summary_zh

**DON'T:**

- 不动 `generate_section` 的实现 / 提示词
- 不删 `llm_brief_item` 字段（保留作为可见的"曾经的中文版"用作 debug）
- 不做整页拒收（per-item 粒度）
- 不加新依赖
- 不改 LLM 评分阈值
