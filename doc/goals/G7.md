# Goal 7 — 跨日 DOI 去重

P2 quality fix (A1 from the post-P1 analysis). After this goal, a paper
that already appeared in any past day's digest will not appear again.
Same-day re-runs are still idempotent.

---

## 一句话目标

Pipeline 在 URL 去重之后、关键词打分之前，按规范化 DOI 过滤掉**之前任何一天**
出现过的条目；当天的 DOI 落库到 `data/seen_dois.json`，re-run 同一天保持稳定。

## 已有基础

- `src/ecobio_daily/scoring.py`：`deduplicate_items` 已经按 URL 去当日重复
- `src/ecobio_daily/models.py`：`SourceItem.url` / `SourceItem.id` 大多包含 DOI
  - Crossref：`url` 形如 `https://doi.org/10.1111/1758-2229.70366`
  - OpenAlex：`url` 通常也是 doi.org 跳转
  - bioRxiv：`url` 是 `https://www.biorxiv.org/content/10.1101/...`
  - 部分源：完全没有 DOI（保留）
- `data/` 目录已有 `.gitkeep`，子目录已被 `data/raw/*` `data/processed/*` `data/cache/*` 写过——
  **要新加 `data/state/` 让 seen_dois.json 持久化**，并在 `.gitignore` 加 `data/state/*` 例外保留 `.gitkeep`

## 范围

**DO:**

- 新建 `src/ecobio_daily/dedup.py`：
  - `extract_doi(item: SourceItem) -> str | None`
    - 从 `item.url` / `item.id` 用正则 `10\.\d{4,9}/[^\s/]+` 抓 DOI
    - lowercase 标准化；去掉尾部标点和 query string
    - 抓不到返回 `None`
  - `load_seen_dois(path: Path) -> dict[str, str]`
    - 返回 `{doi: first_seen_date_iso}`；文件不存在返回 `{}`
  - `save_seen_dois(path: Path, seen: dict[str, str]) -> None`
  - `filter_seen(items: list[SourceItem], seen: dict[str, str], today: date) -> list[SourceItem]`
    - 丢弃：`item` 有 DOI 且 `seen[doi]` 存在且 `< today`
    - 保留：无 DOI；DOI 不在 seen；DOI 在 seen 但 `>= today`（同日 re-run 幂等）
  - `update_seen(seen: dict, items: list[SourceItem], today: date) -> None`
    - 给每个有 DOI 的 item 写 `seen[doi] = today.isoformat()`（若不存在）
- 改 `src/ecobio_daily/pipeline.py`：
  - 在 `deduplicate_items` 之后、`score_item` 之前插入 DOI 过滤
  - 状态文件路径：`output_root / "data" / "state" / "seen_dois.json"`
  - 渲染成功后再写 seen_dois（保证失败 run 不脏写）
- `.gitignore`：
  - 加 `data/state/*` + `!data/state/.gitkeep`
- 新建 `data/state/.gitkeep`（空文件）
- 新建 `tests/test_dedup.py`：
  - `extract_doi` 各种 URL 形态
  - `extract_doi` 大小写归一
  - `filter_seen` 跨日命中 → 丢
  - `filter_seen` 当日命中 → 保留（幂等）
  - `filter_seen` 无 DOI → 保留
  - `update_seen` 不覆盖已有更早日期
- 改 `tests/test_pipeline.py`：
  - 新增端到端测试：两份 items 模拟"昨天 + 今天"，跨日条目被去除

**DON'T:**

- 不改 URL 去重逻辑（互补，不替代）
- 不做 fuzzy 去重 / embedding 去重（E 层才做）
- 不改 LLM 评分 / 简报生成
- 不动 `config/llm.yaml` / `config/digest.yaml`
